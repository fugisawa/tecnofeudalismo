# Tecnofeudalismo: Análise do Tecno-Autoritarismo no Vale do Silício

📊 **Relatório Acadêmico** + 🕸️ **Visualização Interativa**

## Visão Geral

Este projeto investiga a convergência entre a elite tecnológica do Vale do Silício e ideologias autoritárias entre 1998-2025, mapeando conexões financeiras, ideológicas e de propriedade entre atores-chave.

## Componentes

### 1. Relatório Acadêmico (Tecnofeudalismo.md)
- Análise detalhada de ~700 linhas
- 10+ seções temáticas
- 80+ fontes verificadas
- Score de qualidade: 9.0/10

### 2. Visualização Interativa React
- Rede de 35+ atores e 57+ conexões
- Filtros por cluster e tipo de conexão
- Modo apresentação guiada
- Performance otimizada
